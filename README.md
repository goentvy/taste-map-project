# Taste Map Project

**맛집 지도 기반 정보 공유 서비스**  
React + Spring Boot 기반의 풀스택 개인 프로젝트입니다.

---

## 프로젝트 구조

- `front` 브랜치: 프론트엔드 개발
- `backend` 브랜치: 백엔드 개발
- `main` 브랜치: 문서 및 배포 정보 관리

---

## 기술 스택

### Frontend
- Vite
- React
- TypeScript
- Axios
- Kakao Map SDK

### Backend
- Spring Web
- Spring Boot DevTools
- Spring Boot Actuator
- Spring Security
- Spring Data JPA
- MariaDB
- Lombok
- Validation

---

## 실행 방법

### 프론트엔드

```bash
cd frontend
npm install
npm run dev
```

### 백엔드
```bash
cd backend
./gradlew bootRun
```
